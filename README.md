# HumanoidVLN — Project Webpage

Project page for **HumanoidVLN: A Physics-Grounded Simulator and Benchmark for Vision-Language Navigation Across Diverse Humanoid Embodiments**.

The HTML, images, and videos are synchronized from `humanoidvln/site/` in the benchmark workspace. Paper content follows the LaTeX manuscript in `paper/HumanoidVLN/`, including authors, affiliations, robot specifications, benchmark results, and figures.

Preview locally with `python -m http.server`. This repository serves https://humanoid-vln.github.io/ through GitHub Pages.

Official affiliation logos are pending; the page currently displays full institution names. Paper, code, and dataset releases remain forthcoming, as stated in the manuscript.
